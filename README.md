# احتساب ناصبیت — Ehtisab e Nasibiyat

The 12 volumes of the Urdu book **احتساب ناصبیت** as PDFs, compressed losslessly from the original
scans (same page images, smaller files). The *Ehtisab e Nasibiyat* Android reader app downloads its
volumes from here; you can also download them directly.
